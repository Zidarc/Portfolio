# Data-Dash

**Data-Dash** is a data analytics and visualization project that focuses on cleaning, structuring, and presenting multi-source datasets using **Power BI** and **Excel**.  
The project provides interactive dashboards to explore sales trends, music genre performance, and regional metrics.

---

## ✨ Features
- Cleaned and transformed multiple Excel datasets for structured analysis.
- Built **5+ interactive Power BI dashboards**.
- Comparative insights across sales, genres, and regional performance.
- Presented findings to an audience of 50+ stakeholders.
